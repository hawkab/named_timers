# WAKA:Named timers

**WAKA:Named timers** — статическое PWA-приложение для создания именованных таймеров процесса с последовательными этапами. Приложение работает без backend, хранит данные локально в браузере и подходит для публикации через GitHub Pages.

## Для чего это нужно

Приложение помогает заранее разложить любой ограниченный по времени процесс на понятные этапы: интервью, созвон, занятие, тренировку, регламентную проверку или выступление.

Практический кейс: подготовка к интервью по **System Design**. Можно создать процесс на 60 минут и заранее задать этапы: функциональные требования, нефункциональные требования, happy path, API, схема данных, масштабирование, exceptional path и вопросы кандидата. Во время тренировки таймер будет последовательно переключать этапы, показывать остаток времени, проигрывать звук и отправлять локальное уведомление.

## Возможности

- создание нескольких процессов;
- настройка этапов с названием, описанием и длительностью;
- автосохранение в `localStorage`;
- drag-and-drop сортировка этапов;
- запуск последовательного прогона;
- переход к предыдущему и следующему этапу;
- импорт и экспорт всех процессов в JSON;
- тёмная и светлая темы;
- русский и английский интерфейс;
- PWA-установка;
- локальные браузерные уведомления и звук таймера.

## Локальный запуск

```bash
cd docs
python3 -m http.server 8080
```

После запуска открыть:

```text
http://localhost:8080
```

## Публикация на GitHub Pages

В настройках репозитория выбрать:

```text
Settings → Pages → Build and deployment → Deploy from a branch → main / docs
```
